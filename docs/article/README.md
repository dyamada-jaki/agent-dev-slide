## 2. 掲載メモ

[Qiita の記法](https://qiita.com/Qiita/items/c686397e4a0f4f11683d)・[Zenn の記法](https://zenn.dev/zenn/articles/markdown-guide)の公式ガイドを2026-11-07に確認した。原稿は両方に共通する見出し・段落・表・リンク・画像だけを使い、Mermaid、Qiita の `:::note`、Zenn の `:::message`、脚注、HTML、front matter は使っていない。

- タイトル: 1行目の `# …` を各サイトのタイトル欄へ移し、本文からは消す。本文の見出しは `##` から始まる（Zenn のガイドは見出し2から始めることを勧めている）。
- 図: 両サイトとも相対パスは使えない。各サイトのエディタで [images/overview.png](images/overview.png) をアップロードし、原稿の `[![…](images/overview.png)](images/overview.png)` の2か所を、アップロード後の画像 URL に置き換える（画像をリンクで包む書き方は Zenn のガイドに記載あり）。アップロードの操作はガイドに載っていないので、投稿時に実画面で確かめる。
- URL だけの行は両サイトでリンクカードになる。原稿では URL を文中のリンクにしているので、カードにはならない。
- タグ（Qiita）・topics と絵文字・記事の種類（Zenn）は本文の外で設定する。候補は「AI」「ClaudeCode」「Codex」「スクラム」「開発プロセス」程度。決めるのは投稿時（投稿はスコープ外）。
- 公開前に各サイトのプレビューで、表の折り返し、画像の拡大、リンク先を確かめる。
