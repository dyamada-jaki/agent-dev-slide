## 次に切る Issue

以下は後続の構成候補で、受け入れ条件は未確定。本文の「Issue 1本の流れ」へ進む前に、スクラムの用語方針を決める。

1. Issue 1本の流れ: 仕様から切り出し、計画・実装・レビュー・マージ・ふりかえりへ進む流れ。
2. 人間の判断と記録: 計画承認、採用判断、改善の採否。Issue・PR・レポート・ADR への記録。
3. 始め方: 環境の準備、仕様の議論、最初の Issue、起動係。

全体の枚数と時間配分は、15分程度の LT に収まるように計画と通し確認で調整する。
