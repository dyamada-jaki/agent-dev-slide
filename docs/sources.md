## 使い方

- 読むための参照先。元リポジトリを変更しない。
- 各スライドのノート（HTML コメント）に、内容を裏付ける資料の URL を残す。
- 参照版を更新するときは差分を読み、説明への影響と新しい SHA を記録する。最新版の仕様を推測で混ぜない。
- 成果や効果を説明する場合、参照元に根拠がない数値・優劣を追加しない。
