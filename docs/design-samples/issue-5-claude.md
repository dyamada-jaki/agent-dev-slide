## 案のねらい: 紙と藍、明朝の見出し

両案とも配色は紙白・墨・藍で近い。この案で比べてほしいのは、次の3点。

| 軸 | この案の選び方 |
|---|---|
| レイアウト | 表紙は左寄せのタイトルと右の挿絵。説明ページは基準原稿の箱と矢印の構成を保ち、余白を広めにとる |
| 装飾 | 装飾は Overstrata の「深度バー」（緑・土・紫の3色の帯）1つだけ。見出しの下と表紙の左端に置く。影・グラデーションの面は使わない |
| 人物の使い方 | 人物は「人間」を表す場面にだけ置く。図を読ませる3枚目には置かない。エージェントは人の姿でも、ロボットなどの絵でも描かない |

## 見比べる手順（Orca のブラウザ）

1. 各案の worktree で `npm ci` のあと `npm run dev` を起動する（`.env` の `HOST_PORT`。この案は `5281`、Codex 案は `5282`）
2. この案を開く: `orca tab create --url http://localhost:5281/samples/issue-5-claude/index.md --json`
3. Codex 案を別のタブで開く。予定の例は `http://localhost:5282/design-codex.md`（実際のパスは Codex 案の PR で確かめる）
4. 両タブを 1280×720 にして、← → キーで同じページを交互に見る。この案は 1ページ目が表紙、2ページ目が Spec・Issue・Orca、3ページ目が人間の判断。URL の末尾に `#1`〜`#3` を付けても同じページを開ける
5. PDF で見るときは `npm run build:samples` のあと `dist/samples/issue-5-claude/index.pdf` を開く。CI の成果物（`slides`）にも同じ PDF が入る

## 今後のルールの候補（採用前）

1. 色は意味で使う: 説明の本体は藍、人間の判断は金。装飾のためだけに色を足さない
2. 装飾は深度バー1つ。見出しの下（横）と表紙の左端（縦）だけに置く
3. 見出しは明朝、本文はゴシック。手元と CI に両方ある書体だけを指定する
4. 人物は「人間」を表すときだけ置き、エージェントは人の姿で描かない。図を読ませるページには置かない
5. 人物はデフォルメしたレナ・ヨナを基本にし、紙色の地で生成して乗算で背景に溶かす。参照画像・生成日・加工をこの形式で記録する
6. 本文の最小は 19px（補足）、説明の本文は 23px 以上
