# 表紙の比較見本（2026-11-08）

主題は「AI との開発にスクラムを取り入れる」。人間がタイトル案 B を選び、副題を外して主題を大きく出すこと、開発の様子を描く挿絵を使うことを希望した。背景を藍色にする案は、見本を見て判断する。

- [HTML の比較見本](index.html): A は紙色、B は藍色。文字と挿絵の配置をそろえた。
- [2ページの PDF](cover-study.pdf): 表紙だけを比較する資料。本編8枚の PDF とは別。
- [挿絵](scene.png): レナ1人が計画を確認し、AI の開発者2人がノートパソコンで作業する場面。
- [生成指示](image-prompt.txt): 内蔵 image_gen で生成。既存のレナと開発者2人の画像を画風・人物の参照に使用した。
- 本編への採用と背景色の決定は、この見本の確認後に行う。表紙の主題以外の文字は入れていない。

## 作り方と確認

HTML の文字は編集でき、人物画は背景が透明な PNG。色は共通テーマの紙色 `#F6F4EE` と藍 `#1F2B47`、題名は既存の明朝体を使う。画面は1280×720。閲覧用の案名と案内は PDF に出力しない。

このフォルダの `render.mjs` をリポジトリ直下から `node docs/design-samples/cover-2026-11-08/render.mjs` で実行すると PDF を生成する。既存の puppeteer-core とローカル Chrome を使用し、依存は追加していない。画像の読み込みとフォントを待ってから生成する。

2026-11-08、Chrome の HTML 表示と PDF の全2ページを1280×720で目視し、タイトルの欠け・重なり・画像欠けがないことを確認した。ローカルの明朝体による見本で、CI の Noto による表示は未確認。本編原稿・共通テーマ・本編の共有 PDF は変更していない。
