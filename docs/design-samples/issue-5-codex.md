## 比較したいこと

配色が近い案どうしでも、余白・情報の並べ方・人物の置き方で読みやすさは変わる。この案では、面で囲うカードを減らし、紙色の上に文字と細い罫線を置く。見出しの明朝体と本文のゴシック体で、項目の位置と説明の違いを示す。

| ページ | 配置の意図 | 人物の使い方 |
|---|---|---|
| 表紙 | 左揃えの大きな題名と広い余白。元の副題2行を保つ | 置かない |
| Spec・Issue・Orca | 横3列の同じ幅で全項目を示し、矢印で関係を示す。参照先は列の下端にそろえる | 置かない |
| 人間の判断 | 左に人間、右に3つの判断。見出しを2行にして余白を確保 | レナ・ヨナが資料を見比べる挿絵を、人間の説明の直下に置く |

人物は人間を表す。AI エージェントの PO・開発チーム・開発者には割り当てない。作品内の舞台や物語は説明へ持ち込まない。

## 生成と比較の手順

```sh
npm ci
npm run check
npm run build:samples
npm run dev
```

本編の `build`・`build:pdf` は変更していない。`build:samples` が別に見本のHTML・PDFと画像を生成する。CI は `npm run check` の後にこのコマンドを実行し、既存の `slides` artifact に `dist/` 全体を含める。

| 対象 | 原稿・プレビュー（このworktreeのポート） | 生成物（Git管理外） |
|---|---|---|
| 本編6枚 | `http://localhost:5282/index.md` | `dist/index.html`、`dist/agent-dev-slide.pdf` |

1. `.env` の `HOST_PORT=5282` を確かめ、上記の開発サーバーを起動する。
2. Orca のブラウザで `http://localhost:5282/design-codex.md#1` を開く。別タブで Claude Code案の `http://localhost:5281/samples/issue-5-claude/index.md#1` を開く（相手側の実際のパスは相手の PR で確認する）。両方の開発サーバーを各担当のポートで起動しておく。
3. 両タブの viewport を1280×720にそろえる。Orca CLI の `exec --command "set viewport 1280 720"` を使い、`eval --expression "({width: innerWidth, height: innerHeight})"` で実寸を確認する。コマンドには対象タブの `--page` を付ける。

5. 人間が採用・修正・保留を判断する。比較と判断の記録はコーディネーターが担当する。確認後は各担当が自分の開発サーバーを `Ctrl+C` で止める。
