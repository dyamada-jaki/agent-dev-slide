# 導入2枚目の全体像・検討用見本

2026-11-03、人間の「全体イメージを俯瞰できる絵」と「それで一回見てみたい」に応じた PO の図案。本編への採用や Issue #4 の実装開始を意味しない。

- 内容の基準: [仕様2.3](../../../docs/spec.md#23-スクラムの考え方用語との対比) の再計画で合意した説明。
- 目的: 最初に人間・AI の役割と開発の循環を一緒に見せ、後続ページの詳しい説明につなぐ。
- 画面: 人間と AI の PO の対話、4つにまとめた工程、人間の3つの判断、開発チームと開発者、次の開発への改善を示す。既存の紙色・藍色・金色と人物素材を再利用する。
- この図は全操作の手順書ではない。成果確認の内訳（相互レビュー、AI の PO の受け入れ、人間の判断）、採用・マージ、スクラムのイベント名との対比は後続ページで説明する案。
- 固定期間のスプリント、独立したスクラムマスター、デイリースクラムはこのプロセスに設けていない。開発チームをスクラムマスターに対応付けない。
- 人間はステークホルダーとして確認し、PO として作る方向や優先順位も判断する。図の AI の PO にすべての責任を移した説明ではない。

## 表示・出力

```sh
npm run build:overview
python3 -m http.server 5274 --bind 0.0.0.0 --directory dist/issue-4-overview
```

Orca のブラウザで `http://localhost:5274/` を開く。PDF は同じ URL の `overview.pdf`。

- 編集元: `index.html`。文字・線・配置は HTML / CSS / SVG として編集できる。
- 出力: `dist/issue-4-overview/index.html`、`overview.pdf`、`overview.png`。HTML は人物画像を埋め込んだ単独ファイル。
- 生成: 既存の Marp が利用する `puppeteer-core` と Google Chrome を使う。既定は macOS の Chrome。別の場所では `CHROME_PATH` を指定する。新しい依存パッケージは追加していない。
- 形式: 16:9、1280×720。HTML は表示領域に合わせて縮小し、PDF は1ページに固定する。PowerPoint ファイルはまだ制作していない。
- 確認: PDF を PNG に変換して目視し、日本語テキストの抽出・1ページ・16:9も確認。本編の生成対象には含めない。
